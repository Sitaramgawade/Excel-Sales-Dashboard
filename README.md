# Excel-Sales-Dashboard
An interactive Excel dashboard created to analyze and visualize Super Store sales performance using real-world business metrics. This project helps track sales trends, customer behavior, regional performance, and product category insights in a simple and professional format.
<br><hr>
📊 Pivot Table Analysis

This pivot table shows sales, quantity, orders, regions, categories, customer types, and monthly data in a simple way. It helps to understand business performance and find useful insights from the sales data.
